🔗 Workflow vs Independent Scheduling

Workflow Scheduling

Tasks have dependencies and precedence order.

Independent Scheduling

Tasks are independent and can run in any sequence.

Food story: You cannot deliver food before packing it, and you cannot pack it before cooking it.
Take Order
   ↓
Cook
   ↓
Pack
   ↓
Deliver

Workflow is represented using a Directed Acyclic Graph (DAG).

V = set of tasks
E = set of dependencies

t1 → t2 → t3

Parent Task

Must finish before the child task can start.

Child Task

Depends on a parent task.

Entry Task

Task with no parent.

Exit Task

Task with no child.

📋 Goal of Task Scheduling

The goal is to map tasks to appropriate resources so that one or more objectives are optimized.

Reduce completion time

Finish all tasks sooner.

Improve utilization

Avoid idle cloud resources.

Satisfy user needs

Meet different user requirements.

Important: The lecture notes that scheduling can be NP-complete, so a good suboptimal answer found quickly is often preferred over an exact optimum that takes too long.

Heuristics

A heuristic is a rule-based, problem-specific method that tries to find a good near-optimal answer in reasonable time.

FCFS

First Come First Serve.

Min-Min

Chooses tasks based on smaller minimum completion values.

Max-Min

Chooses tasks based on larger minimum completion values.

Round Robin

Resources are assigned in circular order.

SJF

Shortest Job First.

LJF

Longest Job First.

Metaheuristics

Metaheuristics are high-level strategies that combine lower-level methods for exploration and exploitation of the search space.

PSO

Particle Swarm Optimization.

ACO

Ant Colony Optimization.

GA

Genetic Algorithm.

DE

Differential Evolution.

SA

Simulated Annealing.

Easy difference: Heuristic = smart rule. Metaheuristic = broader smart search strategy.

🐦 Particle Swarm Optimization (PSO)

PSO is an optimization technique proposed by Kennedy and Eberhart in 1995. It is based on swarm movement and collective intelligence.

Bird-flock story: Imagine birds searching for food. Every bird remembers the best place it personally found, and the entire flock knows the best place discovered by any bird.
Bird = Particle
Food = Solution
pbest = Best position found by one particle
gbest = Best position found by the whole swarm

How PSO Searches

Each particle is a candidate solution. It adjusts its movement using its own experience and the experience of the swarm.

Velocity Update

V(t+1) = wV(t) + c1 × rand() × (Xpbest − X(t)) + c2 × rand() × (Xgbest − X(t))

Position Update

X(t+1) = X(t) + V(t+1)

Meaning of Symbols

SymbolMeaning
V(t)Velocity of particle at time t
X(t)Particle position at time t
wInertia weight
c1, c2Learning / acceleration factors
rand()Random number between 0 and 1
XpbestParticle's best position
XgbestGlobal best position
Simple meaning of the formula: Keep some old movement + move toward my best position + move toward the group's best position.

PSO Algorithm

1. Randomly initialize particle positions and velocities
2. Calculate fitness
3. Update personal best (pbest)
4. Update global best (gbest)
5. Update velocity
6. Update position
7. Repeat until termination condition
8. Return approximate global minimum
