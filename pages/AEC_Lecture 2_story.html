Chapter 1

🚀 Why Did Cloud Computing Become Necessary?

Imagine you start an online shopping company called ShopFast. In the beginning, you have one website, one server and only a few customers.

Story: Everything works smoothly until your company becomes popular. Suddenly you have millions of users, mobile apps, customer analytics, large databases, images, videos and much more traffic.

But what if you only need this extra capacity during a festival sale?

Easy idea:

Cloud Computing = Rent and use

Chapter 5

📚 NIST Definition of Cloud

The NIST idea can be remembered without memorising a very long sentence.

Exam-friendly meaning:
Cloud computing provides shared computing resources over a network, on demand, and those resources can be quickly provided or released.

Typical resources include:

🌐 Networks

Connectivity and bandwidth.

🖥️ Servers

Processing and compute power.

💾 Storage

Files, databases and data storage.

📦 Applications

Software delivered through cloud platforms.

🧩 Services

Managed capabilities offered by the provider.

Most Important Exam Topic

⭐ The Five Essential Characteristics of Cloud

⚙️

On-Demand Self-Service

Get resources yourself whenever needed.

🌍

Broad Network Access

Use cloud services through different devices over a network.

🏊

Resource Pooling

Shared resource pool serves many users.

📈

Rapid Elasticity

Resources can quickly scale up or down.

📏

Measured Service

Usage is monitored and measured.

1. On-Demand Self-Service

ATM analogy: You do not call the bank manager every time you need cash. You use the ATM yourself. Similarly, cloud users can create or request resources without needing manual interaction each time. 
Old IT:
Email IT Team → Approval → Setup → Wait

Cloud:
Login → Click Create → Resource Ready

2. Broad Network Access

Same cloud service
      ↓
Laptop
Phone
Tablet
Desktop

You can access cloud capabilities using different devices through the network.

3. Resource Pooling

Hotel analogy: A hotel has many rooms and allocates them to guests as needed. Cloud providers similarly share physical and virtual resources among many customers. 
Large Resource Pool
        |
  -----------------
  |       |       |
User A  User B  User C
Important term — Multi-tenancy: One cloud infrastructure can serve multiple consumers, similar to one apartment building housing many families.

Location Independence

You usually know that your data is in the cloud, but not exactly which physical machine or storage device is handling it.

4. Rapid Elasticity

Rubber-band analogy: A rubber band expands when you pull it and contracts when released. Cloud resources can similarly increase and decrease according to demand. 
Normal traffic:
2 servers

Festival sale:
2 → 5 → 20 → 100 servers

After sale:
100 → 20 → 5 → 2 servers

5. Measured Service

Electricity-meter analogy: Your electricity provider measures the units you consume. Cloud systems also measure CPU time, storage, bandwidth and other usage. 
CPU Hours
Storage GB
Bandwidth
Active Users
        ↓
Measured and reported
O B R R M
Mnemonic: “Online Business Requires Resources & Measurement.”

Exam-Ready Lines

  1. Cloud Computing: Shared computing resources are delivered over a network on demand.
  2. On-Demand Self-Service: Users can obtain computing resources automatically whenever required.
  3. Broad Network Access: Cloud resources are accessible over the network using different devices.
  4. Resource Pooling: Provider resources are shared among multiple consumers and dynamically allocated.
  5. Rapid Elasticity: Resources can quickly increase or decrease according to demand.
  6. Measured Service: Resource consumption is monitored and measured for control and billing.
